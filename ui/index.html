What should your contacts see you as? Only they ever see it. It is sent inside the encrypted handshake.

Allow screen capture

macOS lets an app read the screen only after you allow it once. Nothing was sent.

  1. Open System Settings → Privacy & Security → Screen & System Audio Recording
  2. Turn on P2P Chat. If it is already on, switch it off and on again: macOS counts an updated build as a new app
  3. Quit P2P Chat (Settings → Quit app), open it again, then click the button again
